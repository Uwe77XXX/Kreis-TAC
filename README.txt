KreisTakt – private Tablet-Web-App

STARTEN
1. Den Ordner auf einen Webserver legen (HTTPS empfohlen).
2. index.html im Browser öffnen.
3. iPad: Safari > Teilen > Zum Home-Bildschirm.
4. Android: Chrome > Menü > App installieren / Zum Startbildschirm.

Zum lokalen Testen am Computer:
- Im Ordner ausführen: python3 -m http.server 8000
- Dann http://localhost:8000 öffnen.

Enthalten:
- 4-Spieler-Hot-Seat
- Spielernamen und feste Teams Blau+Rot / Grün+Schwarz
- geheimer Kartentausch und Sichtschutz
- 64-Felder-Spielkreis, Häuser und Vorfelder
- Meisterkarten, TAC, Trickser und Sonderkarten
- automatisches Speichern im Browser
- Hoch- und Querformat

Hinweis:
Dies ist eine eigenständig gestaltete, private Umsetzung. Die sehr seltenen Regelketten aus mehreren TAC-/Narr-/Teufel-Sonderfällen sollten vor längeren Partien noch gezielt getestet werden.

NEU IN VERSION 1.1
- Kartenhilfe: Beim Antippen einer Karte erscheint ihre Funktion.
- Auch beim geheimen Kartentausch kann eine Karte zuerst angesehen und danach bestätigt werden.
